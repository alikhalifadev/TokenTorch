# TokenTorch

TokenTorch is a distributed edge computing framework that accelerates real-time data processing through scalable, autonomic orchestration.

TokenTorch is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/TokenTorch.git`
2. `cd TokenTorch`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure TokenTorch, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
